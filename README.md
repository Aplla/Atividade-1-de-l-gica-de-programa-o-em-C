# Atividade 1 de lógica de programação em C

Projeto desenvolvido durante meus primeiros estudos de lógica de programação utilizando a linguagem C.

## Objetivo

Essa atividade teve como principal objetivo praticar os fundamentos da programação em C, especialmente:

* Estruturas condicionais
* `switch case`
* Entrada e saída de dados
* Variáveis
* Fluxo lógico
* Interação com usuário no terminal

## Sobre o projeto

O programa simula um sistema simples de autoatendimento de hotel.

O usuário pode:

* informar o número do quarto
* acessar serviços do hotel
* solicitar atendimento
* realizar pedidos
* deixar avaliações sobre serviços

Além disso, o projeto também marcou meus primeiros testes com validação de entrada e estruturas de repetição utilizando `while`.

## Observações

Este projeto foi desenvolvido enquanto eu ainda estava aprendendo os conceitos básicos da linguagem C.

Decidi manter o código original no GitHub para registrar minha evolução como programador e acompanhar minha trajetória de aprendizado ao longo do tempo.

## Tecnologias utilizadas

* Linguagem C
* GCC
* Visual Studio Code

## Aprendizados

Com esse projeto consegui praticar:

* lógica de menus
* uso de `switch case`
* controle de fluxo
* validação básica
* interação com usuário
* organização inicial de código

Também comecei a entender melhor como estruturas de repetição funcionam na prática.
